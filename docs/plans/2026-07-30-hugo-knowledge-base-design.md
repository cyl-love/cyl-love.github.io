# Hugo 知识库博客重构设计

## 目标

将现有 Hexo + Butterfly 博客迁移为 Hugo 站点，整体信息架构和交互接近
`https://yuy0ung.github.io/`，同时保留现有文章、分类、标签、图片、文章日期和旧文章 URL。

## 技术路线

以 `Yuy0ung/Yuy0ung.github.io` 的 Hugo 布局结构为起点，在当前项目中维护独立副本，
不通过 Git 子模块或运行时远程依赖引用上游仓库。站点使用 Hugo Extended 构建，
静态资源、模板和内容全部保存在当前目录中。

## 信息架构

- 首页展示按分类分组的文章知识树，文章条目包含标题和发布日期。
- 桌面端为三栏布局：左侧知识树，中间正文，右侧文章目录。
- 移动端隐藏两侧栏，保留顶栏、搜索、正文和主题切换。
- 顶栏包含头像、站点标题、首页、关于页、搜索和深浅主题切换。
- 保留关于、友链、分类和标签页面；分类和标签不占用首页主要视觉空间。

## 内容迁移

- 将 `source/_posts/*.md` 迁移到 `content/blog/` 下的分类目录。
- 保留 `title`、`date`、`tags`、`categories` 和 `abbrlink`。
- 为每篇文章生成 `url: /posts/<abbrlink>.html`，保持线上旧链接有效。
- 将 `source/images/` 迁移到 `static/images/`。
- 将正文中的 `../images/...` 引用统一改为 `/images/...`。
- 迁移关于页与友链数据，并转换为 Hugo 内容或 Data 模板。
- 不自动改写文章正文表达、标题或分类名称。

## 页面与组件

### 顶栏

顶栏固定在视口顶部。左侧显示头像、站点标题和首页图标；右侧显示关于入口、
搜索按钮和主题开关。窄屏下收起非必要文字，确保控件不重叠。

### 首页知识树

分类默认展开，嵌套分类可折叠。文章标题和日期之间使用点状引导线。
桌面端悬停文章时显示简短摘要；触屏设备不启用悬停预览。

### 文章页

左侧目录树默认折叠并自动展开当前文章所属路径。中间显示文章标题、日期、
标签和 Markdown 正文。右侧显示粘性 TOC，并高亮当前阅读章节。

### 搜索

Hugo 构建时生成 `index.json`。搜索弹窗在浏览器内按标题、摘要和正文过滤，
支持键盘上下选择、Enter 跳转和 Escape 关闭。移动端使用全屏搜索界面。

### 代码与主题

代码块提供语言标识、复制按钮和横向滚动。主题选择存入 `localStorage`，
首次访问遵循系统主题，避免页面加载时闪烁。

## 视觉方向

采用克制的文档型界面：白色/近黑正文背景、中性灰侧栏、蓝色交互强调色，
细边框分隔区域，不使用大幅背景图、营销式卡片或装饰性渐变。圆角控制在 6px 内，
重点保证长篇安全技术文章、代码块和多级目录的扫描效率。

## 部署

GitHub Actions 在推送主分支时安装指定 Hugo Extended 版本，执行 `hugo --minify`，
并通过 GitHub Pages 官方 Actions 发布 `public/`。`baseURL` 设置为
`https://cyl-love.github.io/`。

## 错误处理与兼容

- 构建时检测缺失标题、日期、分类、重复 `abbrlink` 和无法解析的 Front Matter。
- 迁移时检测正文引用但不存在的本地图片，并输出明确文件名。
- 为无分类文章提供“未分类”目录，不丢弃文章。
- 保留 `404.html`，提供返回首页和搜索入口。
- 兼容当前文章内的 HTML、代码围栏和外部链接。

## 验证标准

- Hugo 构建无错误，20 篇文章全部生成。
- 旧 `/posts/<abbrlink>.html` URL 均存在。
- 所有本地图片引用均能解析，不出现站内 404。
- 首页目录树、搜索、折叠、主题切换和代码复制可用。
- 桌面端 1440x900 与移动端 390x844 无横向溢出、文字遮挡或控件重叠。
- 随机抽查长文章、含大量图片文章和代码密集文章的排版。
